# Smart Irrigation Platform – REST API Reference

Base URL: `/api/v1`

---

## 1. Authentication (`/api/v1/auth`)

### `POST /auth/register`
Creates a new account and associated role profile.
- **Payload**:
  ```json
  {
    "email": "farmer@example.com",
    "password": "Password@123",
    "full_name": "Ramesh Patel",
    "role": "farmer",
    "phone": "+91 98765 43210",
    "farm_name": "Patel Farms",
    "district": "Nashik",
    "state": "Maharashtra"
  }
  ```
- **Response**: `201 Created` with JWT access token and user payload.

### `POST /auth/login`
Authenticates credentials and returns a Bearer JWT.
- **Payload**:
  ```json
  {
    "email": "farmer@smartirrigation.org",
    "password": "Farmer@123"
  }
  ```
- **Response**: `200 OK`
  ```json
  {
    "access_token": "<JWT_STRING>",
    "user": {
      "id": 1,
      "email": "farmer@smartirrigation.org",
      "full_name": "Ramesh Patel",
      "role": "farmer"
    }
  }
  ```

### `GET /auth/me`
Header: `Authorization: Bearer <token>`
Returns profile of the authenticated user.

## 2. Weather & Geocoding (`/api/v1/weather`)

### `GET /weather/geocode?query={location_name}`
Searches coordinates using Open-Meteo Geocoding API with in-memory caching.
- **Response**:
  ```json
  {
    "location": {
      "name": "Nashik",
      "latitude": 19.9975,
      "longitude": 73.7898,
      "state": "Maharashtra",
      "country": "India"
    }
  }
  ```

### `GET /weather/current?lat={lat}&lon={lon}&location_name={name}`
Fetches current temperature, humidity, wind, 3-day forecast rainfall, and FAO-56 $ET_0$.

## 4. Crops & Suitability (`/api/v1/crops`)

### `GET /crops`
Returns all verified reference crops.

### `POST /crops/recommend`
Ranks top-5 suitable crops based on multi-factor agronomic compatibility.
- **Payload**:
  ```json
  {
    "soil_type": "loamy",
    "soil_ph": 6.8,
    "temperature_c": 26.0,
    "relative_humidity_pct": 50.0,
    "water_availability": "Medium"
  }
  ```
- **Response**: List of 5 crops with suitability scores, ideal pH/temp, irrigation system, risks, and pest precautions.

## 5. Farmer-Specialist Consultations (`/api/v1/consultations`)

- `GET /consultations`: Returns consultations filtered by role permissions.
- `POST /consultations`: Farmer submits new question with issue category, description, image URL.
- `POST /consultations/<id>/messages`: Appends message (with `is_specialist_advice: true` when author is a specialist).
- `PATCH /consultations/<id>/status`: Updates case status (`open`, `in_progress`, `resolved`).
- `POST /consultations/<id>/rate`: Farmer submits 1-5 star rating and review.

---

## 6. Marketplace & Commerce (`/api/v1/marketplace`)

- `GET /marketplace/categories`: Catalog categories.
- `GET /marketplace/products`: Filter and search catalog.
- `POST /marketplace/products`: Retailer adds new product.
- `GET /marketplace/cart`: Retrieve current user shopping cart.
- `POST /marketplace/cart/items`: Add product with quantity to cart.
- `DELETE /marketplace/cart/items/<id>`: Remove item from cart.
- `POST /marketplace/checkout`: Atomic transaction verifying stock, creating order, and mock payment.
- `GET /marketplace/orders`: List orders for current customer or retailer.
- `POST /marketplace/quotations`: Farmer requests bulk equipment quote.
- `POST /marketplace/quotations/<id>/respond`: Retailer submits price bid.

---

## 7. Administrator Endpoints (`/api/v1/admin`)

Requires Role: `admin`
- `GET /admin/analytics`: Platform KPIs, role distribution, water savings.
- `GET /admin/users`: User management table.
- `PATCH /admin/users/<id>/status`: Activate or deactivate account.
- `POST /admin/specialists/verify/<id>`: Toggle specialist verified badge.
- `GET /admin/ml-metrics`: MAE, RMSE, R², feature weights.
- `GET /admin/dataset-sample`: Inspect 1,500 records dataset.
- `GET /admin/audit-logs`: Security audit trail.
